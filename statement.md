# Project Statement

## Project Title

**Student Grade Predictor**

## Problem Statement

Students' academic performance is affected by multiple measurable factors such as study habits, attendance, sleep, and previous academic performance. A small predictive system can demonstrate how these factors can be processed with Python and machine-learning techniques to estimate a student's final score.

## Scope

The project covers:

- Generation and storage of a structured student-performance dataset.
- Input validation and data loading.
- Training of regression models.
- Evaluation and comparison of models.
- Prediction of an individual student's final score.
- Basic analytics and visualization.
- Automated validation tests.

The project does not claim to provide a clinically, institutionally, or statistically validated assessment of real students.

## Target Users

- Students learning Python and introductory machine learning.
- Instructors demonstrating a complete Python/ML workflow.
- Beginners interested in data processing and predictive modeling.

## High-Level Features

1. Generate/load student data.
2. Validate prediction inputs.
3. Train Linear Regression and Random Forest models.
4. Compare model performance using MAE and R².
5. Predict an individual final score.
6. Convert the score into a grade band.
7. Generate an actual-vs-predicted graph.
8. Run automated tests.
